# 待测试

## 上游与参考项目 P1 / P2 适配

- 画布切图需要确认可拖动分割线、选中删除、增加横/竖分割线并重置为等分网格；非等分切片的像素边界、顺序和数量需要与预览一致。
- 画布工具栏上传、拖拽和文件选择需要用多张图片验证：每张图独立进入现有 Blob/S3/R2 存储流程，部分文件失败时不影响其他文件创建节点。
- 多选节点后需要确认“导出选中”生成 ZIP，包含 `selection.json`、节点连接和原始图片文件；导入或读取导出数据时不应出现视频/音频字段。
- 生图工作台结果和历史卡片需要确认同时展示请求尺寸/质量与接口实际尺寸/质量；接口返回 `revised_prompt` 时单独展示，不覆盖用户原提示词。
- 配置弹窗安全导出需要确认文件不包含 API Key、S3/R2 Access Key、Secret Key 和后台公开渠道快照；导入前显示版本和内容预览，导入后保留当前设备已有密钥且不自动开启同步或对象存储。
- 本地配置和后台渠道需要确认可选择“火山方舟”协议；Seedream 参考图生图应通过 `/images/generations` JSON 的 `image` 数组提交，蒙版编辑应明确提示不支持且不降级。
- 远程火山方舟渠道需要确认仍经过 Go 代理、算力点结算和 AI 日志；标准 OpenAI 渠道不能因为模型名包含 Seedream 而被错误改写协议。
- 后台渠道声明式异步生图适配需要分别验证同步直接返回、创建任务后轮询成功、失败状态、超时和用户取消；结果应归一为 OpenAI `data` 图片数组，只有实际返回图片才保留算力点消费。
- 声明式适配需要确认只接受创建路径、任务 ID、状态、结果和错误字段，不执行 JavaScript；普通状态文本不能被误识别成图片，配置错误时返回明确错误并返还算力点。
- 画布左侧面板需要确认元素缩略图、素材和提示词搜索可用，点击元素能定位并选中，点击素材或提示词能插入画布；调整宽度和收起后不遮挡顶部栏、底部工具栏或 Agent 右侧栏。
- 通用节点组需要确认多选后可建立组，拖动组会同步移动成员，成员单独移动/缩放/删除后组边界会自动更新；解除组保留成员，删除组不删除成员，将已有组成员重新成组时不会同时留在旧组。
- 后台标准 JSON 提示词来源需要确认数组和 `{ items: [] }` 两种格式可同步，字段限制为 `id/title/prompt/coverUrl/preview/tags`；来源内容不能执行脚本，关闭来源后分类不再展示，个人文本素材仍能从左侧素材面板使用。
- 生图历史需要用大量 4K 图片确认缩略图以 localforage LRU 缓存、空闲时后台补图，历史滚动不再同时解码所有原图；预览和下载仍必须使用原图。
- Canvas Agent 运行时需要确认所有带顶部账户区的页面都会显示 Agent 任务状态，点击状态可返回画布；任务结束或停止后状态自动消失。

## 渠道、导航与 AI 超分

- 本地直连模式需要分别选择两个同模型不同名称的本地渠道生成图片，结果卡片应显示实际选择的渠道名称，不能显示渠道 ID 或沿用之前的远程渠道。
- 右上角账户菜单的会员中心、我的订单和管理后台需要在新标签页打开，当前创作页面和未保存输入不能被替换。
- 顶部账户菜单、前端路由和后端 `/api/leaderboard/images` 中不再存在生图排行榜功能；旧链接应返回未找到，而不能加载残留数据。
- 画布图片节点的“AI 超分”需要确认可以选择本地或云端图片模型、渠道和 2K/4K 目标，生成后在源节点右侧创建新图片节点并保留连线。
- AI 超分需要分别验证 Images、Responses、Gemini 和 Ark 支持参考图的渠道；不支持自定义目标尺寸或图生图的渠道应返回真实错误，不能自动改用浏览器插值。
- 云端 AI 超分需要确认经过 Go 代理并正常记录渠道、模型、耗时和扣点；请求失败或无图片结果时应按现有规则返还算力点。
- AI 超分结果需要确认写入当前 Blob/S3/R2 图片生命周期，结果节点显示真实宽高、文件体积、模型、目标尺寸和生成耗时，下载仍使用完整原图。

## 高分辨率图片编辑与接口夹具

- 画布裁剪、局部遮罩和切图弹窗需要分别使用 4K 横图、4K 竖图验证：首次打开稳定显示，放大、缩小、适应视口和按住空格拖动画布可用，编辑层与图片不发生偏移。
- 裁剪弹窗需要确认自由比例、固定比例、拖动和八方向缩放仍按原图像素计算，生成的裁剪节点没有清晰度下降。
- 切图弹窗需要确认网格线在缩放后仍与图片对齐，生成子节点的数量、顺序和像素范围保持正确。
- 局部遮罩需要确认超大图会生成最长边不超过 1920、宽高为 16 倍数的 PNG 工作图；弹窗应同时显示工作图和原图尺寸。
- 局部遮罩生成的配置节点需要确认手动执行时上传的参考图与 mask 宽高完全一致，生成成功后重试仍能读取已保存的工作图。
- 删除局部重绘配置节点和相关画布引用后，需要确认工作图可被现有图片存储清理流程回收，不会长期占用 IndexedDB 或服务端对象存储。
- 本地执行 `cd web && npm run mock:image-api`，按 [图片接口故障模拟器](image-api-fixtures.md) 逐项验证 Images API、Responses API 和 `/images/edits` 的成功/失败判定。
- `mock-large-base64` 需要确认前端不会出现 `Maximum call stack size exceeded`，`mock-504-html` 和 `mock-stream-error` 需要确认不会消费成功结果或展示伪图片。

## 纯生图分支与 PR #43 合并

- 后台模型渠道和配置弹窗本地渠道需要确认新增 OpenAI/Gemini 协议选择；Gemini 渠道需要确认模型列表拉取成功。
- Gemini 本地渠道需要确认文本问答、文生图和参考图图生图可用；云端 Gemini 渠道需要确认仍经过后端代理、AI 日志和算力点消费/返还。
- Gemini 蒙版局部重绘需要确认直接提示“不支持蒙版编辑”，不会自动降级到 `/responses`。
- 画布配置节点和提示词浮层需要确认生成中按钮切换为“停止”；点击停止后请求取消，节点恢复空闲状态，不进入失败态。
- 画布文本生成、图片生成、参考图生成和反推提示词需要分别确认停止生成不清除已经成功返回的结果。
- 本地 `canvas-agent` 需要确认可按 `canvas-agent/README.md` 启动，并在画布助手 Agent 模式中填写地址和 token 后连接成功。
- 本地 `canvas-agent` 需要确认使用仓库内置版本启动后，Agent 执行 `canvas_generate_image` 或 `canvas_run_generation` 时，网页侧确认后会自动触发配置节点开始生图。
- 本地 `canvas-agent` 需要确认新建空对话后第一次发送消息不会再出现 `not materialized yet`、`no rollout found` 或 `thread not found` 错误，历史面板读取空会话时应显示为空而不是出错。
- 本地 `canvas-agent` 需要确认对话运行中发送按钮会切换为停止按钮，点击后当前 Codex 对话会停止且面板恢复可输入状态。
- 网页 Agent Loop 需要确认可读取当前画布、读取选区、创建文本节点、创建生图流程、选择节点和触发文本/图片生成。
- Agent 工具列表和提示词需要确认不出现视频、音频、Seedance 或 WebDAV 能力。
- 分支 `codex/video-audio-upstream-v0.3.3` 需要确认已经保存并推送当前视频/音频合并成果。
- 当前 `main` 分支需要确认顶部导航、画布工具栏、配置弹窗、我的素材、素材库和 API 不再出现视频/音频入口。
- 生图底部工作台需要在桌面端确认“开始创作”按钮固定在右侧操作区；移动端确认按钮不遮挡、不溢出。
- 文本生图、参考图生图、局部重绘、图片拆分、图片放大、反推提示词和图片保存素材需要逐项验证。
- 生图工作台需要用 4K 或 10MB 级别图片复测 `/images/edits` 图生图，确认参考图上传不再因为大图 base64 转换报 `Maximum call stack size exceeded`。
- 生图工作台大图下载需要确认下载按钮保存的是完整原图 Blob，文件大小和直接打开云端链接下载的文件一致或仅存在正常响应头差异。
- 生图工作台生成结果卡片需要确认成功结果会展示实际图片宽高和文件体积。
- 生图工作台历史/全部结果卡片需要确认标签区会展示首张图片文件体积，多图结果会额外展示总文件体积。
- 生图工作台结果卡片和历史记录点击“重试”需要确认会复用原记录的渠道、模型、尺寸、质量、接口模式、格式、审核、超时、流式和失败重试配置。
- 生图工作台底部工作台尺寸选项需要确认已包含 1:1、16:9、9:16 的 4K 尺寸，选择后能按对应参数发起请求。
- Agnes Image 2.1 Flash 渠道需要确认默认请求体不再携带额外 seed；如果仍返回 422，需要结合渠道请求日志确认是否为渠道侧参数限制。
- 画布反推提示词需要确认 `/chat/completions` 流式返回后文本结果节点能展示最终内容，配置节点和结果节点耗时不再一直为 0，且不会在已返回内容后因为尾部残缺流块标记失败。
- 画布局部重绘需要确认只创建提示词节点和配置节点，不自动发起请求；手动运行后能正确计时并展示结果。
- 画布局部重绘需要确认遮罩图通过 `/images/edits` 随原图一起提交，不跨协议降级到 `/responses`。
- 配置弹窗“选择模型”需要确认和后台管理一样走 `/api/admin/settings/channel-models` 拉取渠道模型。
- 生图工作台生成卡片需要确认展示渠道名称，失败重试次数默认 0 且按配置生效。
- 云端渠道生图需要确认未配置失败重试时只发起 1 次 AI 请求；配置重试次数后才按次数重试。
- `/responses` 流式生图需要确认 HTTP 200 但流内出现 `event:error`、`response.failed` 或没有最终图片时会返还算力点，AI 调用日志扣点显示为 0，并按失败重试配置继续重试。
- Responses API 流式返回需要确认能从最终 completed 事件、`response.output`、base64、data URL 或 HTTP 图片 URL 中正确识别图片，不再把已返回图片的 SSE 文本误判为失败。
- 云雾等 `/images/generations`、`/images/edits` 渠道需要确认返回体包含 `b64_json` 或图片 URL 时，即使 JSON 包装被中转站截断或 HTTP 状态非 2xx，前端仍能优先提取图片结果。
- 云雾等耗时超过 60 秒的图片请求需要在服务器 openresty/Nginx 部署环境下复测，确认前端生成卡片不再保存或展示 `504 Gateway Time-out` HTML，而是等待后端最终图片结果。
- univibe 等 `/responses` 渠道需要确认单行 SSE、`response.image_generation_call.partial_image` 和 `partial_image_b64` 能被识别为图片结果；后端 AI 日志和算力点结算不再把这类已返回图片的调用记为失败。
- 上游返回 HTTP 图片 URL 的渠道需要确认生成卡片可以直接展示结果，不再错误包成 base64。
- 算力点日志需要确认 AI 消费和失败返还备注显示模型与渠道信息；失败请求应出现等额消费和返还，成功请求只保留消费。
- 所有带顶部账户区的用户页和后台页需要确认头像旁会显示当前算力点余额，余额变化后刷新用户信息可同步更新。
- “我的素材”文本卡片需要确认长提示词默认收起，详情仍可查看全文。
- 页面右上角需要确认已移除文档跳转按钮。
- R2/S3 图片上传需要确认超时、连接重置或 5xx 时会按 100ms、300ms、900ms 递增延迟重试。

## PR #43 新能力

- 会员中心页面需要确认套餐展示、下单、订单跳转和用户会员状态刷新。
- 我的订单页面需要确认订单列表、取消、模拟支付、刷新支付链接和微信扫码弹窗。
- 管理后台会员套餐页面需要确认新增、编辑、删除、排序和启停。
- 管理后台订单页面需要确认查询、手动标记支付和删除。
- OIDC 配置存在时需要确认登录页显示入口；未配置时不影响普通账号登录。
- ZPay 支付需要用真实网关验证跳转、同步返回和异步通知验签。
- 支付宝当面付扫码支付直连需要真实 AppID、应用私钥、支付宝公钥和 notify_url 联调；前端需要确认下单后展示服务端预创建返回的收款二维码，异步通知验签成功后发放权益。
- 微信支付 APIv3 Native 扫码需要真实 AppID、商户号、APIv3 密钥、商户证书序列号、商户私钥和 notify_url 联调；需要确认下单二维码、异步回调验签解密、appid/mchid/金额/币种校验和会员权益发放。
- 新会员订单号需要确认在支付宝、微信和 ZPay 中都能正常作为商户订单号使用。
- 站点配置需要确认名称、Logo、favicon 会同步影响顶部导航、后台侧栏、页面标题和浏览器图标。
- 生图底部工作台需要复测 1280px 和 1440px 桌面宽度下参数控件更紧凑，接口模式和尺寸不重叠，右侧参考图和“开始创作”操作区不被挤到左侧。

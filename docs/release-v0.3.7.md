# v0.3.7 发布说明

## 主要更新

- 生图工作台历史新增 IndexedDB 轻量索引，默认每页读取 24 条，可切换为 48 或 96 条。
- 历史图片、分类封面和参考图进入视口附近后才加载；本地缩略图最多并行处理 2 张，降低大量 4K 图片同时解码造成的卡顿。
- 普通生成、工作流生成、分类调整、删除和素材迁移统一增量维护历史索引。
- 账号历史快照改为短延迟合并同步，连续生成不再让每张图片分别等待完整历史快照上传。

## 修复

- R2/S3 公网图片未开放 CORS 时直接使用远程地址展示，不再通过跨域 `fetch` 生成缩略图导致卡片空白。
- 账号同步和索引增量刷新时保留当前卡片，避免刷新页面后重复显示骨架。
- 修复发布前 TypeScript 严格检查发现的分页日志过滤和泛型 IndexedDB 读取类型问题。

## 发布前检查

- `go test ./...`
- `cd web && npm exec tsc -- --noEmit`
- `cd web && npm run build`

以上检查在发布提交前均已通过。Next.js 构建仅提示工作区存在多个 lockfile，不影响生产构建完成。

## 部署后验收重点

- 使用 100 条以上历史记录确认首屏只读取当前页，分页和分类总数正确。
- 刷新页面确认骨架只出现一次，账号同步完成后不会再次清空卡片。
- 使用未开放 CORS 的 R2/S3 公网图片确认卡片、预览和下载均可用。
- 连续生成多张图片，确认历史实时出现且账号同步不会逐张阻塞。

详细测试清单见 [待测试](pending-test.md)。

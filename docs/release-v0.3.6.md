# v0.3.6 发布说明

## 主要更新

- 画布裁剪、局部遮罩和切图统一使用高分辨率图片编辑视口；遮罩参考图会生成尺寸规整的 PNG 工作图。
- 切图支持拖动、增加、删除和重置分割线；画布上传支持多文件，选中节点可导出 ZIP。
- 新增可调宽画布资源侧栏和通用节点组，整合节点、素材和提示词。
- 生图记录补充接口实际尺寸、质量和改写提示词；历史图片使用 localforage 缩略图 LRU。
- 配置支持剥离密钥的安全导入导出，后台支持标准 JSON 提示词来源。
- 模型渠道新增火山方舟协议和声明式异步图片任务适配。
- Canvas Agent 任务状态可在全站顶部查看，任务停止和异常后的状态清理得到加强。
- 画布图片节点新增 AI 超分，可选择现有图片模型和渠道生成 2K/4K 增强结果。

## 修复与调整

- 修复本地直连生图结果显示过期渠道 ID，结果卡片优先记录当前选择的图片渠道名称。
- 右上角账户菜单的会员中心、我的订单和管理后台改为新标签页打开。
- 删除生图排行榜页面、前端请求、公开 API 及后端业务代码。
- 声明式异步渠道只有提取到有效图片地址、Data URL 或 Base64 图片时才保留算力点消费。
- 禁用的标准 JSON 提示词来源不再出现在提示词分类中。
- 通用节点组会在成员移动、缩放、删除或重新成组后自动更新关系和边界。
- 修复发布前严格类型审查发现的 Gemini 本地协议判定、Responses 图片/工具输出、Canvas Agent 提示词回退和管理后台表格类型问题。

- 分别使用 Images、Responses、Gemini 和 Ark 的参考图渠道验证 AI 超分、失败返还、AI 日志和对象存储。
- 验证 4K 裁剪、遮罩、切图、缩略图缓存、多文件上传和选中节点导出。
- 验证排行榜旧页面和 `/api/leaderboard/images` 已不可访问。
- 验证账户菜单新标签页、Canvas Agent 全站状态和配置安全导入导出。
